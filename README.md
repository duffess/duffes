# Duffes - Premium Personal Portfolio

A high-end, minimalist personal portfolio developed with React, TypeScript, and Vite. Focused on performance, sophisticated typography, and editorial design aesthetics.

## Features

- **Premium UI/UX**: Editorial-style layout with a focus on white space and modern typography.
- **Micro-interactions**: physics-based transitions and motion design.
- **Performance Optimized**: 100/100 Lighthouse performance metrics.
- **Multilingual Support**: Fully localized content.
- **Bespoke Components**: Custom-built UI library for unique brand identity.

## Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Vanilla CSS with Design Tokens
- **Animations**: CSS Transitions & Framer Motion

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
